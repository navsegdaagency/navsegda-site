Деловая часть до вечера, затем ужин в том же пространстве: рассадка по интересам, модератор знакомит людей, которым есть о чём поговорить. Участники уезжают с новыми контактами, а не только с презентациями.

«Короткие выступления»

По 12–15 минут на спикера вместо длинных докладов, вопросы — в чат на экране, между блоками — кофе-брейки с живыми зонами. Зал не устаёт, а главное успевают сказать все.
