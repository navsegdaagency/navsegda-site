Кабинет проекта: API

Для людей и ИИ-агентов команды НАВСЕГДА. Один проект = одна свадьба. Пара, реализатор, подрядчики и агенты работают с одной и той же карточкой; смета и деньги читаются из таблицы реализации и не дублируются.

КтоГдеДоступ

Как подключиться

  • Базовый адрес: https://109-68-213-160.sslip.io
  • Командные методы - заголовок X-Kab-Key: <KAB_KEY>. Ключ выдаёт Денис. Не вписывайте ключ в код, файлы сайта и сообщения.
  • Публичные методы (пара, бриф, подборка) - токен в пути, ключ не нужен.
  • Тела запросов - JSON, Content-Type: application/json. Ошибки: {"detail": "текст"} с кодом 400/403/404.
  • Если сервер не отвечает и включён VPN - отключите VPN (на Mac Дениса: curl --interface en0).
  • Ссылки из уведомлений ведут на navseg-da.agency/proekty/#<id>.

Правила для ИИ-агентов

  • Паре и подрядчикам ничего не отправлять без команды человека. Ссылки и тексты из ответов отдавать реализатору или Денису.
  • Деньги не трогать: смета, оплаты и маржа живут в таблице реализации, в кабинете они только для чтения. Поле payplan менять только по прямой просьбе реализатора.
  • Не создавать кабинеты для пар без просьбы человека. Для проверок - только проект test-kabinet.
  • Свои выводы и заметки писать в поле notes через PATCH: сначала GET проекта, дописать строку в конец (с датой и подписью, например «28.10 агент: ...»), потом PATCH всей строкой.
  • Массивы (slots, payplan, docs) и объекты (brief, anketa) заменяются целиком - всегда GET перед PATCH, чтобы не стереть выбор пары.
  • Не менять tokens, wishes, likes, selections и events - их пишет сама система.

POST/api/kab/projectsX-Kab-Key

Создать кабинет. pair - название пары как в таблице реализации (по нему подтягивается смета). Если кабинет с таким pair уже есть - вернётся он (existing: true). Паре ничего не отправляется.

Тело
{"pair": "...", "names": "...", "date": "ГГГГ-ММ-ДД", "guests": 60, "venue": "...", "realizer": "Настя", "realizer_tg": "123456789", "manager": "...", "amo_lead": "12345678"}
Пример
curl -s -X POST -H 'X-Kab-Key: <KAB_KEY>' -H 'Content-Type: application/json' https://109-68-213-160.sslip.io/api/kab/projects -d '{"pair":"Миша и Лиза","date":"2027-06-12","realizer":"Настя"}'
Ответ
{
 "id": "misha-i-liza",
 "existing": false,
 "links": {
  "pair": "https://navseg-da.agency/para/?t=<токен>"
 }
}
PATCH/api/kab/projects/{id}X-Kab-Key

Изменить поля проекта. Разрешены: names, date, guests, venue, venue_address, realizer, realizer_tg, manager, stage (0-7), amo_lead, slots, brief, docs, anketa, payplan, notes, timing, archived. Массивы и объекты (slots, brief, payplan, docs, anketa) заменяются целиком - сначала GET, потом PATCH всего массива. Ответ - вся карточка.

Тело
slots:   [{"key":"Ведущий","status":"ok","who":"Ведущий Александр","note":"бриф отправлен","cands":[],"picked":null}, ...]
brief:   {"story":"","people":"","music":"","stop":"","wishes_host":"","wishes_photo":"", ...}
payplan: [{"name":"Предоплата 50%","amount":88000,"due":"2026-11-15","status":"wait"|"paid"}]
docs:    [{"name":"Договор","url":"https://..."}]
anketa:  {"percent":72,"link":"https://navseg-da.agency/anketa-nevesty/?name=..."}
notes:   "строка, дописывать в конец"
Пример
curl -s -X PATCH -H 'X-Kab-Key: <KAB_KEY>' -H 'Content-Type: application/json' https://109-68-213-160.sslip.io/api/kab/projects/test-kabinet -d '{"stage":1}'
POST/api/kab/projects/{id}/briefX-Kab-Key

Создать (или обновить who) ссылку-бриф для роли. Повторный вызов для той же роли возвращает ту же ссылку.

Пример
curl -s -X POST -H 'X-Kab-Key: <KAB_KEY>' -H 'Content-Type: application/json' https://109-68-213-160.sslip.io/api/kab/projects/test-kabinet/brief -d '{"role":"host","who":"Ведущий Александр"}'
Ответ
{
 "role": "host",
 "token": "MJiHt4CbmsRBYKQc",
 "url": "https://navseg-da.agency/brief/?t=MJiHt4CbmsRBYKQc"
}

POST/api/kab/sel/{token}/pickбез ключа

Пара отмечает «нравится» в подборке (on: true/false). Если подборка привязана к слоту - это и выбор в слоте.

Пример
curl -s -X POST -H 'Content-Type: application/json' https://109-68-213-160.sslip.io/api/kab/sel/<токен_подборки>/pick -d '{"item":"a-loto","on":true}'
Ответ
{
 "ok": true
}

Примеры ответов сняты с тестового проекта test-kabinet; длинные списки сокращены («... ещё N»).
